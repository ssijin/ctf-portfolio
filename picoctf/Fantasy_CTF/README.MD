# Challenge: picoCTF - Fantasy_CTF

## 문제 설명 & 접근
Play this short game to get familiar with terminal applications and some of the most important rules in scope for picoCTF.
Connect to the program with netcat:
$ nc verbal-sleep.picoctf.net 49930
picoctf 대회를 가정하고 선택지를 고르는, 윤리와 규칙을 보여주는 문제이다. 간단한 예제에 가깝다.

## 문제 풀이
* Play the game과 Search the Ether for the flag 중 후자를 선택하면 Nyx says, "Oh, I've read about this Ei. You don't want to submit a different players flag! That's against the rules! Even sharing artifact downloads could lead to you finding someone else's flag."가 나온다. CTF 윤리 규칙을 시뮬레이션으로 알려주는 예제인듯하다.

## 결과
전자를 택해 나온 flag를 입력하면 풀린다.
